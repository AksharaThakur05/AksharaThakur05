## 🤖 Featured Robotics Project

### Uncertainty-Aware Target-Following Robot

[**View the repository →**](https://github.com/AksharaRobotics/uncertainty-aware-target-following-robot)

An autonomous target-following robot simulation designed to study how a robot can continue making reliable decisions when perception is **noisy, incomplete, or temporarily unavailable**.

The project integrates perception, estimation, prediction, planning, control, and experimental evaluation into one complete robotic system.

### Core Capabilities

- Camera-like target sensing
- Measurement-noise simulation
- Kalman-filter-based state estimation
- Position and velocity estimation
- Target-motion prediction
- Closed-loop target following
- A* path planning
- Dijkstra path-planning comparison
- Static and dynamic obstacle handling
- Line-of-sight and occlusion modelling
- Collision monitoring
- Failure-case testing
- Tracking-error analysis
- Experimental scenario evaluation

### Research Question

> **How can an autonomous robot make reliable decisions when its perception of the environment is uncertain or incomplete?**
